# Security Policy

## Reporting a vulnerability

Do not report vulnerabilities in a public issue or discussion. Use this repository's private vulnerability-reporting channel. If that channel is not enabled when the repository becomes public, contact a maintainer privately through the contact method listed in the repository profile.

Include a concise description, impact, reproduction steps, and a proof of concept where safe. Do not include secrets, customer data, or destructive payloads.

## Scope

The initial scope is source code and documented self-hosted deployments of OpsRadar. This includes authentication, authorization, sensitive-data exposure, injection, SSRF, and unsafe handling of integration credentials.

Third-party hosted services should be reported to their respective maintainers unless the vulnerability is caused by OpsRadar's integration or configuration.

## Disclosure

Maintainers will acknowledge valid reports, investigate privately, and coordinate a fix before public disclosure. No response-time commitment is made while the project is in transition to open source.
