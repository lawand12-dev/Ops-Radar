## Maintainer technical references

The remaining folders hold implementation references for the legacy application:

- `adr/` — architecture-decision records.
- `specs/` — implementation specifications.
- `design/` — historical design references.
- `dev/` — dated engineering plans and archived implementation notes.

They are not promises of the open-core roadmap. New open-source documentation should describe a runnable behavior, an explicit data contract, or a contributor workflow.

## Public-release status

Historical YC, fundraising, go-to-market, competitor, research, and positioning material has been removed from this working tree. Before changing repository visibility, it must also be removed from Git history and the repository must be scanned for credentials and third-party assets. See [the release gate](./OPEN_SOURCE.md#public-release-gate).
