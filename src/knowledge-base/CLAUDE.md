# OpsRadar Knowledge Base Schema

## Purpose
This wiki contains structured knowledge
about marketing agency operations.
Read this file before every wiki operation.

## Structure
/benchmarks  → hours, costs, ROI by agency type
/tools       → API behaviour and failures per tool
/patterns    → common pain patterns
/failures    → failure modes and fixes
/agency-profiles → how agencies operate by size

## When ingesting new audit data:
1. Read the new information
2. Update relevant existing pages
3. Create new pages if needed
4. Update index.md
5. Add entry to log.md
6. Maintain all cross-references

## When answering audit queries:
1. Read index.md first
2. Find relevant pages
3. Read those pages
4. Use as context before reasoning
5. Never reason from scratch

## Page format:
- Clear heading
- Structured sections
- Links to related pages [[like-this]]
- Last updated date
